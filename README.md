# TechStore — курсовой проект

Интернет-магазин техники на **Laravel 13** (PHP 8.4). Дисциплина «Серверная веб-разработка»
(«Framework на языке PHP»), Московский Политех.

## Что реализовано

### Витрина
- **Главная** — hero-блок, категории с количеством товаров, «Хиты продаж», «Новинки».
- **Каталог** `/catalog` — фильтры по категории, поиск по названию/бренду/описанию,
  диапазон цен, 4 варианта сортировки, пагинация по 9 товаров.
- **Карточка товара** `/product/{slug}` — изображение, цена, остаток, описание,
  характеристики, блок «Похожие товары» (динамический элемент по категории).
- **Корзина** `/cart` — в сессии, изменение количества, удаление, очистка.
- **Оформление** `/checkout` — валидация формы, транзакция: заказ + позиции +
  списание остатков, страница подтверждения `/order/{id}`.

### Административная часть `/admin`
- Вход по e-mail и паролю (сессии, `auth`, защита от CSRF).
- **Дашборд**: количество товаров/категорий/заказов, новых заказов, сумма оплаченных,
  последние заказы, товары с остатком < 5.
- **Товары**: CRUD, поиск, загрузка изображения (диск `public`), флаг «Хит».
- **Категории**: CRUD, авто-slug из названия, запрет удаления непустой категории.
- **Заказы**: список с фильтром по статусу, карточка заказа, смена статуса
  (новый → оплачен → отправлен → выполнен / отменён).

## Запуск

```bash
composer install
cp .env.example .env          # Windows: copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

Открыть http://localhost:8000

**Демо-доступ в админку:** `admin@techstore.local` / `admin12345`

### MySQL вместо SQLite

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=techstore
DB_USERNAME=root
DB_PASSWORD=
```

```bash
php artisan migrate --seed
```

## Структура

```
app/
├── Http/Controllers/
│   ├── HomeController.php        # главная
│   ├── CatalogController.php     # каталог + карточка
│   ├── CartController.php        # корзина
│   ├── CheckoutController.php    # оформление заказа
│   └── Admin/                    # Auth, Dashboard, Product, Category, Order
├── Models/                       # Category, Product, Order, OrderItem
└── Services/Cart.php             # корзина в сессии
database/
├── migrations/                   # categories, products, orders, order_items
└── seeders/DatabaseSeeder.php    # 5 категорий, 18 товаров, админ
resources/views/
├── layouts/app.blade.php         # витрина
├── admin/                        # админка (layout, dashboard, CRUD)
├── catalog/, cart/, checkout/
└── partials/                     # карточка товара, пагинация
routes/web.php                    # все маршруты
public/
├── css/app.css
└── img/products/*.svg            # демо-изображения
```

## Тестовые данные

- 18 товаров (6 из них — «хиты»)
- Администратор: `admin@techstore.local` / `admin12345`

## Проверки

Смоук-тест проходит полный сценарий: карточка товара → 2 добавления в корзину →
оформление заказа → страница заказа → вход в админку → все разделы админки →
фильтр каталога.
